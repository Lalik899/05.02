Записная книжка контактов (WinForms)

Учебный групповой проект по созданию десктопного приложения для управления контактами. Приложение поддерживает сохранение данных в локальный JSON-файл и валидацию полей ввода.

Стек технологий
* Язык программирования: C# (.NET Framework / .NET)
* Интерфейс: Windows Forms (WinForms)
* Архитектурный паттерн: Разделение на слои (Models, Views, Services)

Инструкция по запуску
1. Склонируйте репозиторий на локальный компьютер.
2. Откройте файл решения `Записная книжка контактов.sln` в Visual Studio.
3. Нажмите кнопку **Пуск (Start)** или комбинацию клавиш `Ctrl + F5` для сборки и запуска приложения.

Состав команды и роли
* **stolbov (Тимлид)** — Архитектура проекта, координация, код-ревью, README.md.
* **Артём (Разработчик БД/Логики)** — Реализация модели данных `Contact.cs` и логики сериализации в JSON.
* **Участник 2 (Дизайнер UI)** — Проектирование главной формы, настройка кнопок и таблиц DataGridView.
* **Участник 4 (Тестировщик/Валидация)** — Разработка регулярных выражений для валидации ввода и тестирование.
